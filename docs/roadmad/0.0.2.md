## Improvement

> **Status legend** (corrected after the 0.0.2 review — see `docs/NOT_COVERED.md`):
> `[x]` functional · `[~]` partial (works only in limited cases) ·
> `[ ]` stub — emits a placeholder and is **not** functional.

### Statements

- [x] **`switch`**
- [x] **`throw`**
- [~] **`try`** _(catch error binding is not accessible; no `finally`)_
- [~] **`for` `of`** _(int-only arrays; a `0` element truncates iteration — 0-sentinel)_
- [ ] **`for` `in`** _(stub: iterates a hardcoded `length`/`toString`/`valueOf` list, ignores the real object)_
- [x] **`do` `while`**


### Expressions
- [ ] **`this`** _(stub: always emits a permanently-NULL global; see NOT_COVERED.md)_
- [ ] **regular expression literal** _(stub: returns a dummy pointer; no matching)_
- [~] **Array initializer `[` ... `]`** _(int-only; 0-sentinel terminated)_
- [~] **Object initializer `{` ... `}`** _(flat int fields only; not a first-class runtime value)_
- [~] **Property accessors** _(only identifiers directly bound to an object literal; int props)_
- [ ] **`new` operator** _(stub: returns a dummy pointer, never runs a constructor)_
- [ ] **`delete`** _(stub: always returns 1, deletes nothing)_
- [x] **`void`**
- [ ] **`typeof`** _(stub: always returns `"number"`)_
- [ ] **`instanceof`** _(stub: always returns 1)_
- [ ] **`in`** _(stub: always returns 1)_
- [x] **Comma operator**

> The stubbed/partial items above are the primary motivation for the 0.0.3
> foundation work (a diagnostics gate, a real type-lowering pass, and a
> first-class value model). See `docs/roadmad/0.0.3.md`.
